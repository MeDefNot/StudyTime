# Introduction
 **StudyTime** is a web-based platform designed to efficiently manage and organize shared study spaces, also known as study rooms within university halls.
This is a group project for the course **CSE-252**, **Database Management Systems (Sessional)**, at **Chittagong University of Engineering and Technology**. Our respected Assistant Professor, Sabiha Anan Ma'am, supervised this project.

# How the repository is arranged:

1. **Project Proposal**: initial proposal, motivation, feature mapping, background study of related apps, and description.
2. **Final ERD (Entity-Relationship Diagram)**: Database entities and their relationships.
3. **Relational Mapping**: Conversion of ERDs into relational schemas.
4. **Project Report**: Detailed documentation of the project.
5. **Project Presentation Slide**
6. **Studytime (The Actual Project)**: Source code and implementation of the actual project.
